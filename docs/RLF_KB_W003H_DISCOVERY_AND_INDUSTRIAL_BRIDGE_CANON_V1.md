## Exact physical-listing discovery

An exact physical listing may establish that a photographed evidence instance exists for a controlled style-colour lane when the listing itself explicitly identifies the style and colour.

Discovery alone does not establish that any particular label, code or care instruction is visible. Image-role promotion requires the original image bytes and controlled visual review.

For `M3600::T60`, Mercari item `m76909864831` is retained as an exact physical-listing discovery because the page explicitly states:

- style `M3600`;
- colour `T60` / Snow White / Burnt Red / Navy;
- size `L`;
- twelve product photographs.

Until the gallery bytes are reviewed, the exact full code and all forensic macro roles remain open.

## Workflow state

A GitHub Actions workflow that remains `queued` without a job assignment is stored as `EXECUTOR_QUEUED`.

It must not be represented as:

- executed;
- successful;
- failed source retrieval;
- an empty search result;
- reviewed evidence.

No source or image result may be inferred from a queued collector.
