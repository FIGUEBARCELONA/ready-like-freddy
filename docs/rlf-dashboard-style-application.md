# Aplicación del lenguaje visual RLF al dashboard

El control interno traduce el lenguaje visual local RLF a un entorno de auditoría sin reutilizar imágenes, logos u otros activos que no estén acreditados. La implementación se limita a tipografía, color, composición, espaciado y estados accesibles.

| Elemento | Aplicación en el dashboard |
|---|---|
| Fondo | Blanco cálido y piedra suave para lectura documental prolongada. |
| Jerarquía | Paneles superiores negros para identidad y contexto; serif editorial para títulos; sans legible para metadatos. |
| Acento | Dorado discreto para controles de trazabilidad, no para estados críticos. |
| Estados | Verde solo para verificación factual; ámbar para revisión/cuarentena; rojo para contradicción o prohibición. |
| Navegación | Barra lateral persistente y minimalista, con ruta activa inequívoca. |
| Visuales | Sin fotografías, iconografía de interfaz únicamente; estado cero declarado de forma visible. |

La interfaz no simula volumen documental: los contadores, tarjetas y listas muestran valores procedentes de la base de datos o comunican explícitamente la ausencia de registros.
