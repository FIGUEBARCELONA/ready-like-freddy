# Carta de cobertura mundial RLF

Los cincuenta workstreams se inicializan como capacidad de investigación documental de la KB mundial y no comercial. No se les asigna una fuente, producto, fábrica, período o variante hasta que exista una reserva real y excluyente respaldada por el manifiesto y la evidencia correspondiente.

| Eje de cobertura futura | Regla de asignación |
|---|---|
| Cronología | Desde las décadas de 1940 hasta el 31 de agosto de 2026; cada ventana debe declarar un límite temporal explícito. |
| Productos | Una pieza individual por variante; colaboraciones como productos individuales y nunca como packs. |
| Geografía y fábricas | Cobertura mundial documental; la ausencia de evidencia de fábrica se registra como `NOT_DOCUMENTED`. |
| Identidad | Solo variantes procedentes de registros canónicos y fuentes oficiales trazables; no SKU mappings. |
| Visuales | Sin ingreso hasta que cada asset tenga derechos acreditados, hash, custodia y pertenencia exacta a variante. |

La meta de cobertura de orden 10.000–15.000 productos es una **orientación de capacidad**, no una declaración de exhaustividad. La cola solo podrá reservar ámbitos mediante `KB_DOCUMENTARY_NONCOMMERCIAL`, una huella normalizada y claims excluyentes; cualquier intersección de URL, código, modelo, color o afirmación se bloquea antes de iniciar trabajo.
